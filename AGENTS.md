# Repository instructions

Read CONTRIBUTING.md and docs/BUILDING.md before changes. Keep work scoped to the user request.
Bolus, cartridge/fill, pairing and transport are protected workflows: obtain explicit scoped
maintainer approval before changing behavior, authentication, commands, retries or recovery.
Preserve all unrelated work. Never perform pump actions or install builds without explicit approval.

Use the exact PumpX2 source pin. Do not upgrade it or substitute published binaries silently.
Use synthetic test data only. Do not import private local history, captures, profiles, identifiers,
credentials or unreviewed screenshots. Preserve upstream attribution and license notices.
Build/test evidence is not bench validation. Report failures and limitations honestly.
No public source/APK release while licensing or privacy findings remain unresolved, except for the
owner's explicit October 6, 2026 instruction to publish the privacy-reviewed source and one
experimental APK with the licensing uncertainty and known test failures disclosed. This exception
does not waive privacy, imply upstream permission, authorize future releases, or bypass protected
main-branch review/checks. No pump workflow behavior is unlocked by the publication request.
