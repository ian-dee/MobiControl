# Reporting security issues

Use the repository's **Security → Report a vulnerability** option when available. If it is not
available, open a public issue requesting a private contact channel without sensitive details.
Do not attach pairing/authentication material, raw pump traffic, health data or device identifiers.

This experimental project has no supported clinical release or guaranteed response time.
Do not rely on a development build for therapy. A security report is not authorization for live
pump commands, access to someone else's device, or changing a protected workflow.
